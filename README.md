# Portfolio
A modern, fully responsive personal portfolio website built with HTML5 and CSS3 to showcase my skills, education, projects, and contact information. The website features a premium dark-themed UI, smooth animations, glassmorphism effects, and a mobile-friendly design for an engaging user experience.

**Features**
Responsive design for desktop, tablet, and mobile devices
Modern dark theme with premium UI
Smooth CSS animations and hover effects
Interactive Hero, About, Skills, Education, Projects, and Contact sections
Downloadable resume
Social media links (GitHub, LinkedIn, Email, etc.)
Clean and organized code structure
Built without JavaScript

**Technologies Used**
HTML5
CSS3
Google Fonts
Font Awesome

**Purpose**

This portfolio represents my journey as a web developer and highlights my technical skills, projects, and educational background. It is designed to provide recruiters and visitors with a simple and visually appealing way to learn more about me and my work.
